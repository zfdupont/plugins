Tracked in `docs/factory/`: `factory.yaml`, `backlog.md`, `roadmap.md`, `milestones.md`, and `specs/<job-id>.md`, a copy of the job's `spec.md` that `## Merge` adds before it sets stage `merged`. Hidden in `.factory/`: `board.json`, `dashboard.html`, `jobs/`, `events.jsonl`, `scout.md`, `tune.md`, and the roadmapper's `roadmap-candidates.md`, `roadmap-draft.md` and `roadmap-answers.md`. Whoever first creates `.factory/` (setup, or `CFG event`) writes `.factory/.gitignore` containing `*`, only if that file is missing, so the repo's own `.gitignore` is never edited and an owner can commit their own `.factory/.gitignore` to track, say, `events.jsonl`. `factory_config.py` reads `docs/factory/factory.yaml` (`config_path`). Every `factory/...` path in `skills/*/SKILL.md`, `skills/run/schema.md`, `agents/*.md`, `README.md` and `tests/` moves to the right side. Branch names stay `factory/<job-id>`, and worktrees stay at `../<repo-dir>-factory`. For a repo with the old layout, `CFG validate` prints `factory.yaml: found at factory/, run /factory:setup to migrate` instead of `not found`. After `CFG migration-check` passes, setup offers the move: `git mv` for the tracked files, and a plain `mv` plus `git rm --cached` for the hidden ones. The dashboard hint becomes `cd .factory && python3 -m http.server 8765`.
